# Axon Assistant

Chat with your codebase and apply edits, backed by your Axon account.

## Setup

1. Install this extension (`Install from VSIX…`).
2. Open Settings and set `axon.backendUrl` to your Axon deployment's URL, and `axon.token` to a personal access token generated on that deployment's `/code` page.
3. Run **Axon: Open Assistant** from the command palette.

Full setup instructions are shown on the `/code` page of your Axon deployment.
